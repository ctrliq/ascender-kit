Ascender Command Line Interface
===============================

|prog| is the official command-line client for Ascender.  It:

* Uses naming and structure consistent with the Ascender HTTP API
* Provides consistent output formats with optional machine-parsable formats
* To the extent possible, auto-detects API versions, available endpoints, and
  feature support across multiple versions of Ascender.

Potential uses include:

* Configuring and launching jobs/playbooks
* Checking on the status and output of job runs
* Managing objects like organizations, users, teams, etc...
